## Application Building Context

Read the following files in order before implementing or making any architectural decision:

1. `context/project-overview.md` — product definition, goals, features, and scope
2. `context/architecture-context.md` — system structure, boundaries, storage model, and invariants
3. `context/ui-context.md` — theme, colors, typography, page list, and component conventions
4. `context/design-system.md` — shared Poste visual design source of truth and protected UI rules
5. `context/code-standards.md` — implementation rules and conventions
6. `context/ai-workflow-rules.md` — development workflow, scoping rules, and delivery approach
7. `context/progress-tracker.md` — current phase, completed work, open questions, and next steps

Update `context/progress-tracker.md` after each meaningful implementation change.

If implementation changes the architecture, scope, or standards documented in the context files, update the relevant file before continuing.

## Project Identity

Project name: **Poste**

An AI-powered social media management SaaS for creators, freelancers, and small businesses, with roots in a University of Bamenda student-focused version and a genuine African-market payment/localization angle (Campay mobile money alongside Stripe).
